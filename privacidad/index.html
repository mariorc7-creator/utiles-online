DATOS DE LA CHECKLIST

Almacenamiento local

Las respuestas y los trámites marcados como completados se guardan mediante almacenamiento local del navegador para que puedas continuar otro día.

No pedimos DNI, certificados ni Cl@ve

La herramienta está diseñada como guía. No solicita ni almacena credenciales oficiales ni documentación identificativa para tramitar en tu nombre.

Cómo borrar tus datos

Puedes utilizar el botón «Empezar de nuevo» de la checklist para borrar las respuestas y los trámites completados guardados por esta web en tu navegador.

Analítica opcional con Google Analytics 4

Papeles del Bebé utiliza Google Analytics 4 para conocer de forma agregada cuántas personas visitan la web, qué páginas consultan y si inician o completan la checklist.

Google Analytics no se carga hasta que el usuario pulsa «Aceptar analítica». Si se rechaza, la web sigue funcionando con normalidad y no se activa esta medición. La preferencia se guarda en el almacenamiento local del navegador.

La configuración de analítica desactiva las señales de Google y la personalización publicitaria. No utilizamos esta integración para mostrar publicidad personalizada.

Solicitudes de ayuda profesional

Las funciones de contacto con gestoría se encuentran actualmente pausadas. Si se reactivan en el futuro, esta política se actualizará antes de volver a solicitar datos de contacto.

Papeles del Bebé utiliza la analítica únicamente para mejorar el servicio y medir el uso de la web. Las respuestas de la checklist permanecen en el navegador salvo que una función explique expresamente lo contrario.
